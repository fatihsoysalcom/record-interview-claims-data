# Record Interview Claims Data

This example demonstrates how to meticulously record and manage 'interview claims' or important statements made during professional discussions. It uses a simple Python script to store structured claim data (claimant, context, statement, timestamp, status) in a JSON file, simulating a robust note-taking system. Users can add new claims, view existing ones, and update their status, highlighting the importance of detailed record-keeping for accountability and future reference.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Follow the on-screen menu to add, view, or update claims.
